# HowlsOS

HOWL Sales & Proposal OS cho **Howls Studio** (HOWL LAB).

## Trạng thái

v0.1: prototype bấm được, chỉ dùng mock data (`src/lib/mock-data.ts`), chưa có backend. Spec: [`docs/SPEC.md`](docs/SPEC.md).

## Chạy local

```bash
npm install
npm run dev   # http://localhost:3000
```

Stack: Next.js App Router, TypeScript, Tailwind, shadcn/ui, lucide-react, recharts, @hello-pangea/dnd, sonner.

## Thiết kế

Giao diện tuân theo [`docs/DESIGN.md`](docs/DESIGN.md): phong cách Apple tối giản, giống Personal OS.
